# Player Controller in Godot 4.4  

A FPS 3D movement framework built with the Godot 4 and GDScript.  

## Features  
- **WASD Movement**  
- **Simple Integration** – fully contained within `Player.tscn` for ease of use  
- **Camera Control**

### note
Make you sure add the ("move_left", "move_right", "move_forward", "move_back") in your project settings to the keys you are planning to use.
